# Identifikasi Dataset: Klasifikasi Multikelas

**Klasifikasi multikelas**: kolom target punya **lebih dari 2 kelas**, dan setiap baris hanya punya **1 label**.

| No | Dataset | Kolom target | Jenis sebenarnya | Hasil identifikasi | Notebook |
|----|---------|--------------|------------------|--------------------|----------|
| 1 | Dry Bean Dataset | `Class` (7 kelas) | Multikelas | **Klasifikasi multikelas** | `Dry_Bean/Analisis_Dry_Bean.ipynb` |
| 2 | Credit Card Fraud Detection | `Class` (0 / 1) | Biner | Bukan multikelas | `Credit_Card_Fraud/Identifikasi_Credit_Card_Fraud.ipynb` |
| 3 | PubMed MultiLabel Text Classification | kolom label A, B, C, ... | Multilabel | Bukan multikelas | `PubMed_MultiLabel/Identifikasi_PubMed_MultiLabel.ipynb` |

Penjelasan lengkap "kenapa masuk / kenapa tidak" menyusul, mengikuti format di `../Klasifikasi_Biner/README.md`.
